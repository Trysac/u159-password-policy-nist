# password-policy-nist\n\nPassword verifier checks after NIST SP 800-63B-4: length by code points after NFKC, blocklist and context words, and a k-anonymity breach lookup through a port.\n\n## Problem\n\nMany sign-up forms enforce composition rules and short maximum lengths that NIST no longer recommends, while skipping the checks it does require, such as comparing new passwords against breached and context-specific values. Calling a breach API naively sends the full password hash. This library implements the verifier side of the current NIST guidance with a k-anonymity range lookup that sends only a 5-character hash prefix.\n\n## Installation\n\n```bash\npip install trysac-password-policy-nist\n```\n\n## Usage\n\n```python\nfrom password_policy_nist import PasswordPolicy, check_password\n\npolicy = PasswordPolicy(min_length=15, max_length=128)\nverdict = check_password("correct horse battery staple", policy)\nassert verdict.ok is True\n\nshort_res = check_password("a1b2c3d4e5f6g7", policy)\nassert "too_short" in short_res.violations\n```\n\n## Public API Summary\n\n- **PasswordPolicy**: Frozen dataclass validating policy configuration. Raises `PolicyError` if invalid. \n- **check_password**: Validates passwords against a `PasswordPolicy` with optional context and breach source.\n- **Verdict**: Result dataclass (`ok`, `violations`, `warnings`, `length`, `breach_count`).\n- **sha1_parts**: Returns a 5-character hex prefix and 35-character suffix for range queries.\n- **RangeSource**: Protocol port for breach lookup.\n\n### Why not <best-known alternative>\n\nUnlike heuristic password strength meters (e.g., zxcvbn) that calculate a probabilistic score, this library implements the specific verifier rules and breach lookup mechanisms defined by NIST SP 800-63B-4.\n\n[See Security details](docs/SECURITY.md)
