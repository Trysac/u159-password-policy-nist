# Security Model\n\n## Threat Model\n\n### Defended\n\n- **Full Hash Disclosure**: Only a 5-character hex prefix is transmitted via the `RangeSource` port (k-anonymity).\n- **Leakage**: Password plaintext, full SHA-1 hash, and specific matching suffix are never exposed in `Verdict.__repr__`, log handlers, or event payloads.\n- **NFKC Expansion DoS**: Input length is bounded to 4,096 code points, rejecting invalid inputs without triggering normalization.\n- **Malicious Range Replies**: Rejects range replies > 1 MiB or those lacking valid colon delimiters.\n\n### Not Defended\n\n- **Range Service Observation**: The range service can infer prefix traffic patterns.\n- **Storage**: Does not handle persistent storage hashing (use Argon2id or scrypt).\n- **Rate Limiting**: Does not implement online guessing protection.\n- **Side-Channels**: No mitigation for timing or analysis of custom `RangeSource` implementation network calls.
